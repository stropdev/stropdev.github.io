Using strop

  • The strop CLIOne binary, subcommands for the occasional jobs, flags for everything else. strop --help prints the same reference live (styled when stdout is a terminal, plain when piped).
  • Editor surfacesThemes, completion, indentation and the visual system — the parts of strop you configure rather than drive. For the input grammar see the README's card; for pickers see search.md.
  • Search and the query languageOne bounded qualifier grammar is shared by every picker surface: file find (Space f), content search (Space /), replace (Space R), document symbols, workspace symbols (Space S) and the jump list menu (ctrl-o history, Space j). Qualifiers, highlighting, suggestions and errors behave identically everywhere — what you learn in one field works in all of them.
  • The filesystem workspaceOpen a directory with strop DIRECTORY, :browse, or :e DIRECTORY. Space e reveals the current source in its parent. Browsing keeps the process cwd unchanged; Enter opens a structured entry and -/Backspace goes to its parent. Directory-local Space a opens filesystem actions.
  • SSH, remote editing and containersRemote files are first-class: real buffers, real identity, never a local lookalike. The short version:
  • Local terminals:terminal opens the shell selected by SHELL (or /bin/sh) in a real PTY. :terminal COMMAND runs an explicit command. In a local directory it uses the host; in an SSH directory with an admitted worker it runs on that remote host and retains the endpoint in the modeline, pane title and buffer list. Directory Terminal here (Space a / :fs terminal) uses the same admission decision without changing the editor's cwd. SSH without an admitted worker refuses. An attached container runs through its incarnation-pinned admitted worker; :container-worker enables tools/Search/terminal and the separate :container-edit verifies file authority. The separately labelled Open local terminal / :terminal-local is a deliberate local choice, never a fallback against a remote-looking path. The displayed launch directory is not an unverified live shell cwd and does not follow cd.
