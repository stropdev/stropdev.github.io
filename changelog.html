Changelog

What changed

The last 3 releases, newest first. Tarballs and checksums are on GitHub releases.

0.74.0 — 2026-11-21

Fixed

  • Counted replace: 5rx on abc leaves the line untouched, as in Vim. A count that fits still replaces exactly that many characters.
  • Git blame: Space g B asks you to save a modified buffer instead of showing the disk line's commit beside different text. Pressing Enter on a shifted line cannot open a card for the wrong commit either.
  • Command line: a command such as strop compat refuses an extra file instead of silently discarding it. Use strop -- compat to edit a file named compat. --log=PATH preserves native filename bytes just like --log-file PATH.
  • Pickers: choosing the current buffer in Space b keeps the caret, scroll position and jump history. The results scrollbar reaches the bottom when the last result is selected.
  • Documentation: the 0.71.0 trace-format note now gives the complete EnumMember name.

Compatibility

  • Full session replay uses editor semantics version 10. Use 0.73 to replay a 0.73 recording, or record it again with 0.74.

0.73.0 — 2026-11-20

Fixed

  • Quitting: a filesystem notification already in the queue when the last pane closes can no longer crash the editor. Accepted writes still finish, and the recording can be replayed offline.
  • Read-only startup: strop -R headless SCRIPT FILE honours -R just like the interactive editor. Opening an SSH file at a line keeps both the requested line and read-only mode.
  • Git filenames: staging or unstaging a hunk uses the original pathname bytes, including literal backslashes and non-UTF-8 names. Status shows one row per entry even when its name contains a newline or tab; opening or staging that row acts on the original file.
  • File lifecycle: after :e!, a later external change warns again instead of silently leaving a dirty buffer out of date. Closing all file buffers and quitting on scratch no longer restores those files on the next launch; their recent-file history is kept.
  • Search and Replace: Boolean searches respect smart case for each match, not just each line. The replacement review counts the edits it actually proposes. Reopening Search restores the selected hit and scroll position even when workers returned files out of order.
  • Vim motions and operators: Visual Block $ keeps extending to each row's end after j or k; counted | uses screen columns rather than bytes. Word motions respect combining marks, and a counted iw or aw change with too few words left at EOF no longer changes text or registers.

Compatibility

  • Full session replay uses editor semantics version 9. Replay a 0.72 recording with 0.72, or record it again with 0.73.

0.72.0 — 2026-11-18

Added

  • Tab pages, as in Vim (plans/0113): a second layout of panes over the same buffers. :tab split shows the pane you are in on its own and :q brings the split back; Ctrl-W T moves a pane to a new tab page; :tabnew [file] opens one. gt, gT, 3gt, 3gT and g Tab move between them; :tabnext, :tabprevious, :tabfirst, :tablast, :tabclose [N], :tabonly and :tabmove [N|+N|-N|$] do the rest. Buffers, registers and marks are shared; each tab page keeps its panes, each pane its cursor and jump list.
  • The tab line: with two or more tab pages the top row lists them — the number, the file name of its current pane, +2 for more panes, ● for unsaved changes — with the current one on the text background. With one tab page nothing on screen changes.

Changed

  • The help page is rebuilt (plans/0112): keys are coloured by what they are (plain keys, space and other named keys, ctrl- chords, placeholders), a top line lists nine sections and ]] / [[ or Enter on a name jumps to one, descriptions wrap instead of running off an 80-column screen. The status line names the section the cursor is in, :help completion lists the sections first, and help has no line numbers.
  • :q, :close and Ctrl-W c on a tab page's only pane close the tab page, not the buffer; with one tab page they work as before.
  • Recorded traces from 0.71 are refused (the editor's semantics version is 8: the seed carries tab pages).

Fixed

  • The Windows rows of the help whose descriptions were off screen at 80 columns.
