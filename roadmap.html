roadmap

Where strop is going. Order is priority: editing safety first, new surface area last. The load-bearing detail lives in the repo's plans/ — this page is the public summary.

Shipped

  • The operator-pending preview: d3w shows the cut before you make it, and preview/execute share one resolver.
  • Multicursor (Q toggle, Space c stack), mirrored edits, one undo unit per cascade.
  • Git surfaces as real buffers: commit browser, file history, blame gutter + card, hunk stage/undo/preview, permalinks — all readonly, yankable, searchable text.
  • LSP: hover, goto-definition, diagnostics gutter + picker, clangd's source↔header switch (gs), layered languages.toml (project over user over embedded).
  • Pickers with streaming rg, file/line previews, and modal input fields (Esc → vim normal mode on the query itself).
  • Global replace (Space R) with row/file exclusion and a full-frame apply preview.
  • The 0.3.9/0.4.0 hardening: unicode-honest word motions, arrow keys everywhere, atomic saves with external-change refusal, readonly enforced at the mutation boundary, honest LSP versions + position encoding.

Next

Order is priority. Waves 2–4 of plans/0014-safety-and-restructure.md:

  • Stable identities, not indexes — generational DocumentId/ViewId/PaneId; the parallel-vectors invariant moves into the type system. A document owns text+history+syntax; a view owns selections+scroll; panes place views.
  • Typed coordinates — ByteOffset / LineIndex / ByteColumn / Utf16Column / DisplayColumn with centralised conversions; a unified SelectionSet for cursor, visual, and multicursor.
  • The input registry (0008 grown up): a key-event trie + typed parser state, one command registry driving dispatch, which-key, help, dot-repeat (semantic, not string replay), and macros.
  • ActionPlan everywhere — every command resolves to edits + selections + registers + mode + effects; preview and execute apply the same object. "The preview cannot lie" becomes structural.
  • The neovim differential gate (0006 tier 3): one pinned nvim, property-generated corpora, every new motion ships with diff cases.
  • Git as a data model — HEAD → index → worktree → live document as four explicit states; revisioned SourceLocations; line/selection/symbol history and changed-symbol navigation ahead of more staging UI.
  • Motion canon — ZZ, {/}, (/), ge/gE, H/M/L, zz/zt/zb, Ctrl-d/u/f/b, gv, gi, g;/g,, visual block, :%s and ex ranges, ctrl-^.
  • LSP depth — a server pool (rust + pyright + clangd in one session), references/implementation/symbols/diagnostic traversal, tree-sitter text objects (daf, yic).
  • Grapheme clusters (0001 §5.9) and measured perf: snapshot-based diff/LSP sync, an interval index for the gutter, real benchmarks before any rope surgery.

North star

A reader-first, git-native editor in which every consequential operation is inspectable before it becomes real — vim's grammar, exactly, with git history as a navigable dimension of the document.
