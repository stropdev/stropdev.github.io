Using strop

  • The strop CLIOne binary, subcommands for the occasional jobs, flags for everything else. strop --help prints the same reference live (styled when stdout is a terminal, plain when piped).
  • Editor surfacesThemes, completion, indentation and the visual system — the parts of strop you configure rather than drive. For the input grammar see the README's card; for pickers see search.md.
  • Search and the query languageOne bounded qualifier grammar is shared by every picker surface: file find (Space f), content search (Space /), replace (Space R), document symbols, workspace symbols (Space S) and the jump list menu (ctrl-o history, Space j). Qualifiers, highlighting, suggestions and errors behave identically everywhere — what you learn in one field works in all of them.
  • The filesystem workspaceOpen a directory with strop DIRECTORY, :browse, or :e DIRECTORY. Space e reveals the current source in its parent. Browsing keeps the process cwd unchanged; Enter opens a structured entry and -/Backspace goes to its parent. Space a lists the actions valid here: in a directory the filesystem operations, in a file its operations plus any code actions the language server offers, all in one actions list.
  • SSH and remote editingRemote files are real buffers with their own identity, never a local lookalike. strop reaches a host with plain OpenSSH: nothing is installed there.
  • TerminalsStrop's terminal is Neovim's: a real PTY in a real buffer, one escape chord, and a NORMAL mode that is just NORMAL mode.
  • Vim compatibilityGenerated from the command table (strop compat). ✓ ships exactly; (soon) is a planned slot.
