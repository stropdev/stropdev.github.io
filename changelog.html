Changelog

What changed

The last 3 releases, newest first. Tarballs and checksums are on GitHub releases.

0.76.0 — 2026-11-21

Added

  • Mixed workspaces: optionally declare child project directories and language hints in .strop/workspace.toml. Unlisted projects and loose files stay searchable; executable settings still belong in .strop/languages.toml and require the existing trust decision.

Performance

  • On the mixed-project fixture, warm p95 time to the first selectable row fell from 59.28 to 22.64 ms for rare search and from 30.59 to 8.31 ms for document symbols. Cold workspace symbols with a ready server took 125.00 ms instead of 95.32 ms. Workspace discovery runs on demand.

Fixed

  • Symbol jumps: selecting a document or workspace symbol lands on its token even when non-ASCII text comes before it. Each language server's rows retain its negotiated column encoding; syntax outlines keep byte columns.
  • Workspace symbols: warming a project starts root and configuration discovery in the marker's directory, not its parent. A project-specific command still requires trust for that project.
  • Search results: a cached path can prioritize a fresh check, but cannot hide new files or override an unsaved buffer. Truncated results stay openable individually and cannot authorize collection or replacement review.

Compatibility

  • Full session replay uses editor semantics version 12. Replay a 0.75 recording with 0.75, or record it again.

0.75.0 — 2026-11-21

Added

  • Lean 4: open a .lean file to highlight declarations, proof syntax, strings and nested comments. The grammar ships in the binary; no Lean installation or language server is needed.

Fixed

  • Visual shifts: with a four-space shift width, Vj2> indents the two selected lines by eight spaces. Undo reverses the shift in one step, and . repeats its depth, not just its selection height.
  • Git: staging a hunk through a directory symlink uses the same tracked path as staging through the canonical directory. On an uncommitted line, Enter in the blame card stays in the source instead of opening history at HEAD.
  • Collections: changing context keeps marks and carets on surviving source text. Rebuilding a collection preserves the visible source line in a parked tab, not just the old row number.
  • Batch writes: a review and a collection saving the same file each report their own result. A successful write of an older revision counts as written; edits made in the meantime stay dirty.
  • Installer: if bin/strop is a directory, installation fails without changing its contents or writing a success receipt.
  • Release packaging: two source commits with the same version no longer share an output archive. Publication checks the draft's bytes against those qualified for the tagged commit.

Compatibility

  • Full session replay uses editor semantics version 11. Replay a 0.74 recording with 0.74, or record it again with 0.75.

0.74.0 — 2026-11-21

Fixed

  • Counted replace: 5rx on abc leaves the line untouched, as in Vim. A count that fits still replaces exactly that many characters.
  • Git blame: Space g B asks you to save a modified buffer instead of showing the disk line's commit beside different text. Pressing Enter on a shifted line cannot open a card for the wrong commit either.
  • Command line: a command such as strop compat refuses an extra file instead of silently discarding it. Use strop -- compat to edit a file named compat. --log=PATH preserves native filename bytes just like --log-file PATH.
  • Pickers: choosing the current buffer in Space b keeps the caret, scroll position and jump history. The results scrollbar reaches the bottom when the last result is selected.
  • Documentation: the 0.71.0 trace-format note now gives the complete EnumMember name.

Compatibility

  • Full session replay uses editor semantics version 10. Use 0.73 to replay a 0.73 recording, or record it again with 0.74.
